# ArquiHub 🏛️

**Conecta terrenos con ideas arquitectónicas.**

## 📌 Descripción del proyecto

ArquiHub es una plataforma web que conecta a propietarios de terrenos con arquitectos e inversores, facilitando la creación, publicación y exploración de propuestas arquitectónicas basadas en terrenos reales.

El objetivo es que los propietarios puedan publicar sus terrenos con sus características, medidas, normativas, presupuesto y condiciones, para que distintos arquitectos puedan desarrollar propuestas adaptadas a esas necesidades.

A su vez, los arquitectos, incluidos aquellos que están comenzando su carrera, pueden mostrar sus ideas, construir su portfolio y ganar visibilidad dentro de la comunidad.

## 🎯 Problema que busca resolver

Muchas personas poseen terrenos, pero no saben qué tipo de construcción podrían realizar, cómo aprovechar mejor el espacio o dónde encontrar propuestas arquitectónicas adaptadas a sus necesidades.

Al mismo tiempo, muchos arquitectos principiantes tienen dificultades para mostrar su trabajo, conseguir visibilidad y acceder a nuevas oportunidades profesionales.

ArquiHub busca conectar ambas necesidades en un mismo lugar.

## 💡 Solución propuesta

La plataforma permite que un propietario publique su terreno y reciba diferentes propuestas arquitectónicas de profesionales interesados.

Cada arquitecto debe diseñar su propuesta respetando las características y condiciones del terreno publicado.

De esta manera, un mismo terreno puede tener varias propuestas, lo que permite al propietario compararlas y elegir la que mejor se adapte a sus necesidades.

**Concepto principal: un terreno, múltiples propuestas arquitectónicas.**

## 👥 Tipos de usuarios

### 1. Dueño de terreno

Puede:

- Crear y completar su perfil.
- Publicar un terreno.
- Agregar fotografías y videos.
- Indicar ubicación, superficie, medidas y orientación.
- Especificar normativas, restricciones y características.
- Establecer presupuesto y condiciones.
- Recibir y comparar propuestas arquitectónicas.

### 2. Arquitecto

Puede:

- Crear su perfil profesional.
- Mostrar sus habilidades, especialidades y experiencia.
- Explorar terrenos publicados.
- Consultar las condiciones establecidas por los propietarios.
- Crear propuestas arquitectónicas adaptadas a un terreno.
- Publicar imágenes, renders y descripciones de sus proyectos.
- Construir su portfolio y ganar visibilidad.

### 3. Inversor

Puede:

- Crear un perfil.
- Indicar sus intereses y objetivos.
- Explorar terrenos y proyectos arquitectónicos.
- Identificar oportunidades de inversión.

## ⚙️ ¿Cómo funciona?

1. **Registro:** el usuario ingresa a la plataforma y accede a su cuenta.
2. **Elección del perfil:** selecciona cómo quiere participar en ArquiHub.
3. **Publicación del terreno:** el propietario comparte la información y las condiciones de su terreno.
4. **Exploración:** los usuarios pueden buscar terrenos, arquitectos y proyectos mediante filtros.
5. **Desarrollo de propuestas:** los arquitectos seleccionan terrenos publicados y diseñan proyectos adaptados a ellos.
6. **Comparación:** el propietario puede evaluar las diferentes propuestas recibidas.
7. **Elección:** el propietario selecciona la propuesta que mejor responde a sus necesidades.

## 🧩 Principales secciones

- **Home:** página principal con acceso a terrenos, arquitectos y proyectos.
- **Buscador:** permite encontrar terrenos, arquitectos y proyectos utilizando filtros y características.
- **Detalle del terreno:** presenta las medidas, ubicación, fotografías, normativas y condiciones de una publicación.
- **Perfil del arquitecto:** muestra información profesional, habilidades y portfolio.
- **Publicar:** permite elegir entre publicar un terreno o crear una propuesta arquitectónica.
- **Publicación de terrenos:** formulario para cargar las características y condiciones del terreno.
- **Creación de proyectos:** espacio para presentar una propuesta vinculada a un terreno existente.
- **Perfiles:** espacios diferenciados para propietarios, arquitectos e inversores.
- **Reseñas y galería:** sección destinada a visualizar valoraciones y fotografías de proyectos arquitectónicos.

## 🛠️ Tecnologías utilizadas

El proyecto está desarrollado utilizando tecnologías web fundamentales:

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño, estilos y adaptación a diferentes dispositivos.
- **JavaScript:** interacciones, navegación y funcionalidades del sitio.
- **LocalStorage:** almacenamiento local temporal de determinados datos durante el desarrollo del prototipo.

No se requiere un framework de JavaScript para la estructura actual del proyecto.

## 📱 Diseño y experiencia de usuario

ArquiHub busca ofrecer una experiencia de navegación simple, moderna y profesional.

Sus principales características visuales son:

- Diseño minimalista.
- Paleta de colores basada en azul oscuro, blanco y gris claro.
- Tarjetas para visualizar terrenos, arquitectos y proyectos.
- Fotografías reales de personas, terrenos y construcciones.
- Navegación compartida entre las distintas páginas.
- Diseño adaptable a celulares, tablets y computadoras.

## 🚀 Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Comprobar que los archivos HTML, CSS, JavaScript e imágenes estén correctamente organizados.
4. Abrir `index.html` en un navegador o utilizar la extensión Live Server de Visual Studio Code.
5. Navegar por las distintas páginas y comprobar las conexiones entre ellas.

Las funciones que dependan de una base de datos o de un servidor requieren una implementación adicional si todavía no están desarrolladas.
